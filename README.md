# 海外休闲游戏 AIGC 素材 Skill

一套面向休闲游戏素材团队的 AI 助手工作指南，涵盖创意拆解、图片与视频生产、本地化和素材测试。示例是原创的箭头闯关玩法，可根据真实游戏规则调整。

## 使用

将仓库目录放入你使用的 AI 助手支持的 Skills 目录，或将 `SKILL.md`、`arrow-puzzle.md` 和 `tools.md` 一起提供给助手。输入游戏玩法、目标市场、渠道、授权素材及预算，让助手生成创意方案。

示例：

> 使用这个 Skill，为一款点击箭头依次清空棋盘的休闲游戏，策划面向英语市场的 3 条短视频素材。列出分镜、首帧提示词、制作流程和测试指标。游戏是否提供现金奖励尚未确认，不要添加收益承诺。

`SKILL.md` 是给 AI 的工作指引，并非可直接导入 ComfyUI 的节点图，也不包含模型权重。本项目提供创意模板和上游工作流链接，不表示已经部署、运行或产生实际投放收益。使用第三方工具、模型和素材前，按对应版本核验许可。
